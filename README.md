# 단어장

브라우저에서 바로 여는 영어 단어 학습 페이지입니다. 서버나 설치 없이 `index.html`만 있으면 됩니다.

## 사용 방법

`index.html`을 브라우저로 엽니다.

## 학습 방법

- **카드**: 단어를 누르면 뜻과 예문이 나옵니다. 발음 버튼으로 소리를 들을 수 있습니다. 알아요 / 몰라요로 학습 상태를 표시합니다.
- **퀴즈**: 뜻을 4지선다로 고르는 10문제입니다. 맞히면 아는 단어로 저장됩니다.
- **단어장**: 분류와 검색으로 단어를 찾고, 연습 중인지 아는 단어인지 직접 바꿀 수 있습니다.

단어는 일상, 감정, 학업, 여행으로 나뉩니다.

## 단축키

카드 화면에서 사용할 수 있습니다.

| 키 | 동작 |
| --- | --- |
| Space | 뜻 보기 / 단어 보기 |
| ← → | 이전 / 다음 단어 |
| 1 | 몰라요 |
| 2 | 알아요 |

## 저장

아는 단어와 퀴즈 정답률은 이 브라우저의 `localStorage`에 저장됩니다. 다른 기기나 다른 브라우저와는 공유되지 않습니다.
